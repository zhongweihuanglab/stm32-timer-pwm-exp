# stm32-timer-pwm-exp
## 实验简介
本仓库存放STM32F1定时器相关两个实验源码，基于HAL库开发，使用Keil MDK完成编译调试。
- 任务一：定时器中断实验，配置TIM定时中断，实现定时翻转IO口，观察引脚电平变化。
- 任务二：PWM呼吸灯实验，利用定时器PWM输出，调节占空比，实现LED由暗到亮、由亮到暗循环呼吸效果。

## 开发环境
- 主控芯片：STM32F103C8T6
- 开发工具：STM32CubeMX + Keil MDK-ARM
- 调试工具：ST-Link / DAPLink
- 编程语言：C语言（HAL库）

## 仓库目录说明

## 任务1 定时器中断
1. 使用CubeMX配置定时器TIM，设置预分频、自动重装载值，配置定时周期；
2. 开启定时器更新中断，配置NVIC中断优先级；
3. 在中断回调函数中完成IO电平翻转；
4. 编译下载后，可通过示波器或者LED观察周期性电平变化。

## 任务2 PWM呼吸灯
1. 配置定时器通道为PWM输出模式；
2. 动态修改比较值，不断改变PWM占空比；
3. 延时配合占空比增减，实现LED平滑呼吸效果；
4. 可使用示波器观测PWM输出波形，验证频率与占空比变化。

## 实验现象
- 任务一：LED按照设定定时周期周期性闪烁；
- 任务二：LED亮度连续变化，柔和呼吸，无明显频闪。

## 备注
工程中已经去掉Debug编译生成的冗余文件，只保留源码、CubeMX工程文件。下载后在MDK中打开工程即可直接编译。
